# bootcamp-aws

Esse repositório têm as resoluções dos desafios do bootcamp GFT - Fundamentos de Cloud com AWS feito na DIO.

São 5 desafios, cada um resolvido em uma branch desse repositório.

## [1º Desafio](https://github.com/ronateds/bootcamp-aws/tree/desafio-01-desenho-arquitetura-sistema)
Elaborar e desenhar a arquitetura de um sistema na AWS utilizando o draw.io.

## [2º Desafio](https://github.com/ronateds/bootcamp-aws/tree/desafio-02-step-functions)
Criar uma Step Function

## [3º Desafio](https://github.com/ronateds/bootcamp-aws/tree/desafio-03-cloudformation)
Implementar uma Stack com o AWS CloudFormation.

## [4º Desafio](https://github.com/ronateds/bootcamp-aws/tree/desafio-04-infraestrutura-automatizada-cloudformation)
Implementar uma infraestrutura automatizada com AWS CloudFormation.

## [5º Desafio](https://github.com/ronateds/bootcamp-aws/tree/desafio-05-tarefas-automatizadas-lambda-s3)
Consolidar conhecimentos em tarefas automatizadas com Lambda Function, S3 e DynamoDB.
